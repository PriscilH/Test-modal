# Test-modal

Composant **Modal** développé en **React**, permettant d’afficher une fenêtre modale (pop-up) avec un contenu personnalisé.

---

## ✨ Objectif du projet  
Ce projet contient un **prototype simple et fonctionnel** de modal React, réutilisable pour afficher des dialogues, alertes ou formulaires dans une interface web.

---

## 🛠 Technologies utilisées  
- **React** (JavaScript ES6+)  
- **CSS** pour le style du composant

---

## 🚀 Fonctionnalités principales  
- Ouverture et fermeture de la modal via un bouton ou une action utilisateur  
- Affichage dynamique du contenu à l’intérieur de la modal  
- Overlay pour empêcher les interactions avec le contenu derrière la modal
